# Opera Morning Call

![Opera Morning Call — pré-abertura dos futuros da B3](assets/opera-morning-call-banner.webp)

Extensão para Google Chrome que reúne cotações de referência de WIN e WDO, agenda econômica, indicadores macro, vencimentos e notícias para acompanhar a pré-abertura da B3.

[Acesse o site oficial](https://operamorningcall.vercel.app/)

## Teste local

Abra `chrome://extensions`, ative o **Modo do desenvolvedor** e use **Carregar sem compactação** para selecionar a pasta `extension/`.
