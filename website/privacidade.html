Política de Privacidade

Opera Morning Call — Extensão Google Chrome
Última atualização: Agosto de 2026

A extensão Opera Morning Call respeita sua privacidade. Esta política descreve como lidamos com seus dados.

Coleta de Dados

Esta extensão não coleta dados pessoais identificáveis dos usuários. Preferências como tema e favoritos são armazenadas no navegador (chrome.storage). Quando o usuário valida uma licença, a chave é enviada ao proxy próprio para validação.

Dados de Terceiros

Para fornecer suas funcionalidades, a extensão faz requisições a APIs externas:

  • opera-proxy.datamapleai.workers.dev — Proxy próprio que consulta cotações, indicadores macro e notícias consolidadas. Nenhum dado pessoal é enviado.
  • TradingView — Widget de calendário econômico incorporado via iframe. A TradingView pode coletar dados de navegação anônimos conforme sua própria política de privacidade.

Permissões

A extensão solicita as seguintes permissões no navegador:

  • storage — Para salvar preferências do usuário (tema, favoritos, chave de licença).
  • alarms — Para atualizar dados em segundo plano a cada 60 minutos.

Nenhuma dessas permissões é usada para acessar dados de navegação ou informações pessoais.

Retenção e Exclusão

Nenhum dado pessoal é retido em servidores. As preferências armazenadas localmente podem ser removidas pelo usuário a qualquer momento através do gerenciamento de extensões do Chrome (Remover) ou limpando os dados de navegação.

Alterações

Esta política pode ser atualizada periodicamente. A data da última atualização está indicada no topo da página.
